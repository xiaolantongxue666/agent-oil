# 油训智安 OilTrainSafe

> **面向油气储运工程专业的岗位智能实训与安全能力评测系统**
>
> “岗位—任务—训练—评价—画像—推荐”智能教学闭环。

---

## 项目简介

油训智安是一套面向油气储运工程专业学生、教师及实训教学场景的智能实训与安全能力评测系统。系统将油气储运专业知识、岗位典型工作任务与 AI 技术结合，构建“产业岗位分析 + 专业培养方案版本 + 岗位能力图谱 + 专业知识 RAG + 情境选择实训 + 数据库规则评分 + 班级实施复盘 + 学生自适应学习”的双闭环。

当前围绕油气储运工程专业构建 **6 个完整岗位图谱**，覆盖长输管道站场、油气集输、原油输送、天然气输送、油气计量和燃气输配场站等核心就业方向。

## 项目背景

- 面向职业教育数字化与岗位技能实训需求。
- 结合"揭榜挂帅 / 挑战杯"竞赛场景，强调**真实可运行、可部署、可现场演示**。
- 严格区分**教学模拟**与**公开证据**：工况、学生和评价数据为教学模拟或脱敏数据；岗位与产业证据来自公开页面并保留网址、发布日期、来源级别和内容指纹。

## 功能介绍

- 多岗位能力图谱（PostgreSQL + ECharts Graph）
- 岗位—任务—六维能力热力图及图谱联动高亮
- 教师自定义岗位：公开招聘智能发现、AI图谱草稿、审核发布和版本留痕
- 岗位需求趋势：招聘快照、月度样本变化、高频技能与来源置信度
- 专业知识问答（RAG + 引用来源）
- 教师文件上传、章节/条款分块、知识点映射与启停审核
- 岗位情境选择题实训（无需学生输入长篇文本）
- 数据库规则评分（题目、选项、分值、反馈全程可审计，不调用 LLM 评分）
- AI 依据任务与权威知识生成题库草稿，教师逐题审核后按版本发布
- 教师运行时 Prompt 管理：查看全部模型提示词、变量、调用位置、版本历史，编辑后即时生效并可恢复默认
- 六维能力画像与历史趋势
- 个性化学习推荐
- 教师专业层：岗位发布日期趋势 / 产业证据 / 课程能力覆盖差距 / 培养方案调整草案、审核和版本发布
- 教师课堂层：学生逐题结果 / 班级能力短板 / 高频错题 / 班级教学实施改进计划
- 学生端：知识点掌握度 / 安全类强制补学 / 个性化补学—重练动态路径
- 教师端：学生画像 / 任务管理 / 专业知识库管理

1. **岗位热力图**：以“岗位总体/典型任务 × 六维能力”形成权重矩阵，颜色越深表示岗位要求权重越高，不代表学生成绩。

所有岗位及任务均为基于职业标准的教学化映射，不构成真实生产操作规程。

## 快速开始

本项目采用**自主部署的 Web 应用架构**：前端、后端、工作流引擎、RAG、评价、能力画像和数据库均在本仓库内实现并由 Docker Compose 编排，**不依赖讯飞星辰 Agent 平台**。模型服务仅作为后端可替换的语言推理能力，不负责业务路由、权限、安全决策或最终评分。

### 前置要求
- Python ≥ 3.11（推荐 conda）
- Node.js ≥ 18
- Docker + docker-compose

### 1. 克隆并配置环境变量
```bash
cp .env.example .env
# 编辑 .env，填入 BAILIAN_API_KEY 等（无 Key 时 LLM_USE_MOCK=true 自动降级）
```

### 2. 一键启动（Docker）
```bash
docker-compose up -d --build
```
启动后访问：http://localhost:8080

后端容器启动时会自动执行 Alembic 迁移和幂等种子任务；重复启动不会重复创建岗位、任务、60 条权威知识或图谱关系。

## 环境变量

见 [.env.example](.env.example)。关键字段：

| 变量 | 说明 |
|------|------|
| `DATABASE_URL` | PostgreSQL 连接串 |
| `JWT_SECRET` | JWT 签名密钥（生产必改） |

| `BAILIAN_BASE_URL` | 百炼 OpenAI 兼容端点 |
| `BAILIAN_MODEL` | Qwen 模型名（如 qwen-plus） |
| `QDRANT_URL` | Qdrant 地址 |
| `EMBEDDING_BACKEND` / `EMBEDDING_MODEL` | 本地或 API Embedding 后端及模型 |
| `RERANKER_BACKEND` / `RERANKER_MODEL` | 本地或 API 重排后端及模型 |
| `RAG_RETRIEVE_TOP_K` / `RAG_RERANK_TOP_K` | 检索/重排条数 |

## 阿里云百炼

1. 在阿里云百炼控制台获取 API Key。
2. 填入 `.env` 的 `BAILIAN_API_KEY`、`BAILIAN_BASE_URL`、`BAILIAN_MODEL`。
3. 设置 `LLM_USE_MOCK=false` 以启用真实调用。
4. **API Key 仅存在后端环境变量，不进入 Git、不发送给前端、不写入日志。**

> 无 Key 时，系统以 `MockLLMProvider` 兜底，保证非 AI 链路可运行；当前学生实训成绩仍由数据库选项分值确定，不由模型评分。

## 专业知识导入

仓库内置 `data/knowledge/authoritative_knowledge.json`，包含 60 条经教学化改写的权威知识摘要。每条都具有来源名称、文件/标准编号、章节和 PDF 实际页码，执行 `python -m app.seed` 时会幂等写入数据库；知识数量不足 50、编号重复或来源字段缺失时会直接校验失败。

这 60 条摘要不是仅供知识库列表展示，而是通过 `knowledge_evidence_relations` 与岗位图谱知识点建立正式关系，并参与以下运行链路：

- 岗位能力图谱：知识点节点展示关联的权威依据数量和来源。
- 情境化实训：系统按任务知识点选取相关依据，并在任务页与评价页展示可追溯来源。
- 选择题评价：题干、选项和反馈由数据库题库提供；成绩只按已配置选项分值计算，不调用 LLM。
- 评价结果：保存并展示本次使用的来源编号、章节和 PDF 页码，便于教师和学生复核。
- 专业问答：作为 RAG 检索语料返回带出处的答案。

当前目录引用的权威来源：

- 《燃气储运工国家职业技能标准（2021年版）》：职业编码 6-28-02-01，人社厅发〔2021〕88号。
- 《中华人民共和国石油天然气管道保护法》：中华人民共和国主席令第三十号。
- 《危险化学品企业特殊作业安全规范》：GB 30871—2022。

### 教师上传与章节分块审核

教师端“知识库管理”支持上传 PDF、DOCX、TXT 和 Markdown 文件。上传文件与内置 60 条权威摘要属于两类数据：

- **权威知识摘要**：由项目数据文件幂等写入，具有固定的来源编号、章节和页码，并作为正式权威证据参与问答与评价。
- **教师上传文件**：先解析为章节/条款知识块，经教师审核后进入检索和图谱，不会自动冒充权威来源。

教师文件处理链路：

```text
文件上传
  → 文件哈希与解析后正文重复检测
  → 保留 PDF 页码和文档标题层级
  → 按章/节/条/款优先分块
  → 超长章节二次切分并生成校验摘要
  → 自动推荐六维能力与图谱知识点
  → 教师查看全文、页码、匹配原因和分数
  → 教师启用/停用知识块或调整知识点
  → 仅启用块进入向量检索
  → 仅“启用且已映射知识点”的块进入图谱证据关系
```

目录、前言、参考文献等无关块默认停用；具有明确专业知识点且达到匹配阈值的块默认建议启用。教师的人工审核结果使用独立状态保存，后续系统回填不会覆盖。完全相同的文件或解析后正文会返回 HTTP `409 Conflict`，避免重复知识和重复向量。

```bash
python scripts/import_knowledge.py --path data/standards/xxx.pdf --source-type standard
```
命令行导入支持 PDF / TXT / Markdown；教师页面上传另支持 DOCX。详见 [scripts/import_knowledge.py](scripts/import_knowledge.py)。

> 仓库保存教学摘要和可追溯元数据，不复制标准全文。页面所示“页码”为来源 PDF 的实际页码，内容不作为真实现场操作依据。

## 公开岗位与产业证据

经人工核验的公开证据目录位于 `backend/app/evidence/verified_public_evidence.json`，启动种子任务时幂等写入数据库。岗位样本的时间趋势只使用页面明确日期或正式文件发布日期；`observed_at` 仅表示系统采集时间，永不代替岗位发布时间。官方企业页面/PDF记为高置信度，高校就业网核验转载记为中置信度，缺少可靠日期的联网结果不进入趋势。

产业证据按所选 6/12/24/36 个月窗口参与培养方案分析。每条记录保留标题、发布机构、材料编号、公开网址、发布日期、主题和能力关键词。系统不会把一条企业公告拆成多条来放大需求，跨采集批次还会按原始网址去重。

## AI 生成内容标识与审核

- 专业知识问答的标题、每条助手回答和生成状态均显示“AI 生成内容”，并提示学生依据引用核验。
- AI 题库在教师端显示“AI 生成内容 · 发布前须教师审核”；学生端仅对来源于 AI 的已发布题目显示“AI 生成题目 · 已经教师审核”。
- 岗位能力图谱草稿显示模型、证据数、置信度和“AI 生成内容”标识，教师审核发布前不进入正式图谱。
- 选择题最终成绩只读取数据库选项分值；培养方案调整由证据规则生成并由教师审核，不冒充模型结论。

## 自主部署边界

- 交付形态：Docker Compose 自主部署，可在校内服务器、云主机或离线演示机运行。
- 智能体实现：使用仓库内自研 Workflow Engine 串联澄清、检索、追问、评价、画像和推荐。
- 模型接入：通过后端 LLM Gateway 调用可替换模型；无密钥时使用 Mock 保证非模型业务链路可演示。
- 平台依赖：不使用讯飞星辰 Agent，不把核心逻辑托管到第三方智能体编排平台。

## 推荐演示路径

1. 使用教师账号登录，进入“岗位能力图谱”。
2. 在岗位下拉框中切换 6 个岗位，查看不同岗位的任务热力矩阵和职业标准依据。
3. 点击任意非零权重单元格，展示热力图到“岗位—任务—能力—知识—技能”的联动高亮。

5. 进入“专业知识问答”，验证回答中的来源编号、章节和页码引用。
6. 进入“任务管理”，点击任务的“题库”，选择题数、难度和重点知识点，生成 AI 题库草稿。
7. 逐题核对题干、能力维度、知识点、四个选项、唯一正确答案、分值、反馈和解析，点击“审核并发布本批题库”。
8. 使用学生账号进入“实训中心”，完成已发布的岗位情境选择题，查看规则得分、逐题反馈、权威依据和能力画像。

### 教师新增岗位与需求趋势

教师可选择“AI寻找近期岗位”或“近6个月历史回补”，并可对已保存证据执行“核验发布日期”。系统只接受招聘页 `JobPosting.datePosted`、发布日期元数据、正文明确标注的发布时间，或中置信度的搜索摘要日期；采集时间 `observed_at` 只用于展示采集活动，绝不参与岗位需求趋势归月。没有可靠发布日期的岗位证据仍保留并可用于岗位能力与高频技能分析，但会明确标为低置信度并从时间趋势中排除。需求图不会用零值伪装未覆盖月份：有效发布日期月份少于 3 个时自动展示当前招聘快照、岗位细分类别、采集活动和覆盖时间轴，达到 3 个有效月份后才展示环比与 3 期移动平均。

重点央企采集优先级为中国石油、中国石化、国家管网。中国石化社会招聘通过官网公开结构化接口读取岗位及 `timeStart`，校园招聘接口关闭时只报告“已截止”而不伪造历史岗位；中国石油和国家管网先探测官网招聘入口，再从白名单公开页面检索。每次采集会分别返回“可用、已截止、系统维护、访问受限或连接失败”，并区分官网原始命中、所选时间范围内命中和最终相关岗位，避免把“官网不可访问”误判为“当前没有岗位”。

公开岗位采集采用“重点央企官方来源优先、行业公开页面补充”的顺序，重点覆盖中国石油、中国石化和国家管网。中国石化已接入无需登录的官方结构化社会招聘接口，以官网 `timeStart` 作为高置信度招聘开始时间；中国石油和国家管网优先采集其官方招聘域名及集团官网公开招聘公告。官网出现 412、空响应、验证码或其他访问限制时，系统只记录诊断并使用仍可公开访问的官方公告/搜索结果，不绕过访问控制。

岗位发现采用“公开搜索引擎 + 白名单招聘站点公开关键词查询”双通道。系统会从招聘列表展开职位详情，只分析岗位职责和任职要求主体，排除企业介绍、热门推荐等公共页面噪声；空结果会向教师展示搜索候选、详情展开、正文读取、招聘语义和最终相关岗位等阶段统计。

1. 教师进入“岗位图谱配置”，创建本专业相关岗位草稿并填写岗位别名。
2. 点击“AI寻找公开岗位”，系统仅检索白名单中的公共就业、高校就业和企业官方招聘页面，保存来源网址、采集时间和内容指纹。
3. 点击“生成图谱草稿”，系统依据去重后的真实招聘证据生成典型任务、六维能力权重、知识点和技能点候选结构。
4. 教师修订任务与权重，勾选审核确认后发布；未发布草稿不会出现在学生端图谱。
5. 发布时自动生成对应实训任务草稿，教师可继续进入任务管理和题库审核链路。
6. 在“岗位能力图谱”切换该岗位，查看招聘样本趋势、高频技能、数据来源和置信度。趋势表示系统可追溯样本变化，不等同于全市场岗位总量。
9. 切换教师账号，进入“班级教学实施复盘”，展开查看学生每道题的选择和反馈。
10. 查看班级平均分、能力维度短板和高频错题，生成课堂实施改进计划，修改教学动作并保存为草稿、执行中或已完成；该记录不修改专业培养方案。
11. 进入“产业岗位与培养方案”，按 6/12/24/36 个月查看岗位发布日期样本、产业资料和权威标准形成的能力覆盖差距。
12. 教师可添加并启停产业证据，生成培养方案调整草案，逐项编辑、审核后发布新版本；旧版本自动归档并保留追溯链。
13. 学生进入“自适应学习”，查看由个人逐题实训结果动态生成的知识掌握度、补学与重练路径。

### 双闭环：专业培养方案与学生自适应学习

```text
专业层（不读取学生成绩）
岗位招聘发布时间 + 岗位能力图谱 + 产业政策/报告 + 权威标准
  → 岗位需求与课程能力覆盖差距
  → 培养方案调整草案
  → 教师编辑与证据核验
  → 发布 V2/V3...，旧版本归档可追溯

学生层（不修改专业培养方案）
个人选择题作答明细 + 六维能力画像
  → 知识点掌握度（近期结果权重更高）
  → 安全类低分强制优先
  → 补学知识 → 重练任务 → 完成后实时重算路径
```

### 选择题实训与班级教学实施复盘链路

```text
数据库训练任务
  → 读取启用题目与四个选项（学生端不返回正确标记和分值）
  → 学生按顺序选择并提交
  → 保存题目、所选选项和确定性得分
  → 完成后按能力维度聚合，更新学生能力画像
  → 教师查看个人/班级结果、能力短板和高频错题
  → 基于最新结果生成班级课堂实施数据快照
  → 教师修改教学策略、落实状态和补充说明后保存
  → 新结果产生后再次生成新版本，历史方案不被覆盖
```

### AI 题库生成与教师审核链路

```text
教师选择实训任务、题数、难度和重点知识点
  → 选择“AI 结合权威知识”或“不出网的本地规则模板”
  → AI 模式须由教师明确确认外部数据发送范围
  → 系统按任务知识点/能力检索最多 8 条权威知识证据
  → LLM 仅生成结构化题库草稿
  → 代码校验四个选项、唯一正确答案、分值范围和能力 key
  → 不完整或结构错误的输出使用安全规则模板补齐并显示警告
  → 草稿写入独立题库批次，此时学生不可见
  → 教师逐题修改题干、选项、正确答案、分值、反馈和解析
  → 教师审核并发布整批题库，上一发布版本自动归档
  → 新开始的学生会话使用新版本；进行中的会话继续使用开始时锁定的版本
  → 学生作答和最终评分只读取数据库，不再调用 LLM
```

AI 输出永远不能直接发布，也不能决定学生最终分数。AI 模式仅在教师明确确认后，才会把当前任务元数据和关联权威知识摘要发送至已配置的模型服务；本地规则模板模式不发送外部数据。题库版本保存生成方式、模型、生成时间、授权状态、是否使用规则补齐以及所依据的来源编号、章节和页码，便于教师审计。

### 运行时模型 Prompt 管理

教师端“模型 Prompt 管理”展示系统实际发送给模型的全部运行时模板，包括知识问答、检索词改写、实训策略与情境、实训评价与追问、最终 LLM 子评分、选择题生成、岗位检索词、岗位能力图谱分析，以及结构化 JSON 输出约束与修复。每项 Prompt 同时展示 System Prompt、User Prompt 模板、`{{变量名}}`、代码调用位置和当前版本。

保存 Prompt 后会立即生成并启用新版本，不需要修改 `.env` 或重建容器；历史版本保留，可载入编辑器生成新版本，也可一键恢复代码内置默认值。编辑 Prompt 不能关闭代码层安全守卫、结构校验、混合评分、来源校验和教师审核发布规则。`prompt/油训智安-Claude-Code-总控开发提示词.md` 是项目开发说明，不会发送给业务模型，因此不属于运行时 Prompt。

## 安全边界
- 本系统是**职业教学与虚拟实训系统**，非真实生产/SCADA/DCS/控制/应急系统。
- 不连接真实油气生产设备；不输出可直接用于真实现场的危险控制指令。
- 所有压力/温度/流量/液位/设备状态/故障/工艺条件均为**教学模拟或脱敏数据**。
- 详见 [docs/safety.md](docs/safety.md)。
