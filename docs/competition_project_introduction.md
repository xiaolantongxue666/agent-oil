# 油训智安 OilTrainSafe 项目说明（比赛材料正文）

## 一、项目概述

油训智安是面向油气储运工程专业的岗位智能实训与安全能力评测系统。系统围绕“岗位—任务—训练—评价—画像—推荐”构建教学闭环：以岗位标准、公开产业证据和权威知识为依据，由教师建设与审核教学资源；学生完成岗位情境选择题实训后，系统以数据库规则进行确定性评分，形成六维能力画像并生成补学、重练路径；教师据此开展班级复盘。系统同时提供独立的专业层闭环，以公开岗位发布日期、岗位图谱、产业证据与权威标准支持培养方案版本迭代。

项目坚持“AI 可用但不可越权”：模型只承担语言生成和候选结构任务；教师审核、发布、权限控制、安全守卫和最终成绩全部由可审计的业务代码与数据库规则控制。

## 二、解决的问题与目标

油气储运人才培养面临岗位知识分散、教学资源证据链不足、实训结果难以回流、产业变化难以进入培养方案等问题。项目将岗位要求、任务、能力、知识点、技能点和学习证据关联到统一数据结构中，帮助教师从“经验组织教学”转向“有岗位依据、有来源引用、有评价明细、有版本留痕”的教学管理。

核心目标包括：

1. 用岗位能力图谱将职业标准、典型任务、六维能力、知识点和技能点可视化关联；
2. 建设带来源、章节和页码的可追溯知识底座；
3. 将题库生成、审核发布、学生实训、规则评分和能力画像串成可复核闭环；
4. 将个人学习数据与专业培养方案数据严格隔离，分别支持学生成长与专业迭代；
5. 以 Docker Compose 自主部署，降低现场展示和校内落地门槛。

## 三、功能与数据基础

当前版本内置 6 个完整岗位图谱、43 项种子典型任务、36 条岗位—能力关系、151 条任务—能力关系、17 个知识点、17 个技能点、60 条权威知识摘要、8 个实训任务及 24 道选择题（96 个选项）。岗位覆盖长输管道站场、油气集输、原油输送、天然气输送、油气计量和燃气输配场站等方向。

系统面向三类角色：

- 学生：目标岗位能力图谱、岗位情境实训、训练结果、能力成长档案、个性化学习、岗位学习助手和资料库；
- 教师：教学驾驶舱、岗位图谱配置、知识库管理、任务与题库审核、班级教学复盘、产业岗位与培养方案、学生画像；
- 管理员：用户组织、功能开关、模型配置、运行时 Prompt 版本与审计运行。

## 四、总体架构与代码结构

系统采用 Vue 3 + TypeScript 前端、FastAPI 异步后端、PostgreSQL 事务数据库、Qdrant 向量库和可替换模型网关的自主部署架构。Nginx 对外提供 8080 入口，Docker Compose 统一编排前端、后端、PostgreSQL 和 Qdrant。

```text
Vue 3 / TypeScript / Element Plus / ECharts
                 │  /api + JWT
FastAPI Router / Pydantic / 权限与特性控制
   ├─ 岗位与产业分析   ├─ 知识库与 RAG
   ├─ 题库审核与实训   ├─ 规则评分与能力画像
   └─ 培养方案与教学复盘
                 │
PostgreSQL（业务事实来源） + Qdrant（启用知识块向量索引）
                 │
LLM / Embedding / Reranker Gateway（可替换、可降级）
```

代码按职责分层：`frontend/src/views` 对应学生、教师、管理员的可见页面，`frontend/src/api/index.ts` 统一请求契约，`frontend/src/router/index.ts` 按角色控制页面访问；后端 `app/api/routers` 处理 HTTP 路由，`app/services` 承载跨模块业务，`app/models` 定义 SQLAlchemy 数据模型，`app/schemas` 定义 Pydantic 输入输出，`app/rag` 实现解析、分块、向量检索、重排和引用，`app/workflow` 负责可恢复、可重试的问答流程，`app/safety` 负责教学安全守卫，`app/llm` 是唯一模型客户端入口。

## 五、关键业务链路

### 1. 岗位图谱与公开证据

正式岗位在数据库中组织为“岗位 → 任务 → 能力 → 知识点 → 技能点”。岗位热力图用任务与六维能力权重表示岗位要求；关系图支持随热力单元格联动高亮。教师可从公开招聘页面发现候选岗位，系统保留网址、发布日期、采集时间、日期置信度和内容指纹；只有高/中置信度的可核验发布日期进入月度趋势，`observed_at` 不替代 `published_at`。模型可基于证据生成图谱草稿，但教师审核发布前不会进入正式图谱。

### 2. 知识库与 RAG 问答

权威知识摘要带来源编号、章节和 PDF 页码。教师上传 PDF、DOCX、TXT 或 Markdown 后，系统依次执行文件哈希和正文去重、标题层级与页码解析、章节/条款优先分块、能力与知识点推荐；教师决定块的启用状态和映射。启用知识块才进入向量索引与图谱证据关系。问答工作流按“安全守卫 → 检索词改写 → 检索 → 重排 → 生成 → 输出安全守卫”运行，回答展示 AI 标识与引用。Qdrant 不可用时检索可切换为内存存储，保证教学演示不因向量服务故障中断。

### 3. 题库审核、实训与规则评价

教师选择实训任务、题数、难度和重点知识点后，可选择 AI 模式或本地规则模板。AI 输出需通过四选项、唯一正确答案、能力维度和分值范围等结构校验；缺项由规则模板补齐并警告。草稿写入独立题库批次，教师逐题调整后审核发布，旧版本归档。

学生开始实训时只读取已发布且启用的题目，并锁定 `question_batch_code`；教师发布新版不会影响进行中的会话。学生端绝不返回正确标记和分值。每次选择会写入作答明细；完成后系统按数据库 `option.score` 聚合得分、逐题反馈与能力维度，随后更新能力画像。选择题最终评分不调用 LLM，保证可解释、可审计、可复现。

### 4. 双闭环

学生层只使用个人选择题作答明细与个人能力画像。知识点掌握度按近期结果加权计算，安全类低分优先进入补学与重练路径；每次完成实训立即重新计算。

专业层只使用岗位发布日期样本、岗位图谱、产业证据和权威标准，分析课程能力覆盖差距并形成可编辑的培养方案调整草案；教师审核发布后创建新版本，旧版归档。专业层不读取学生成绩，学生层也不自动修改培养方案，数据边界清晰。

## 六、可信、安全与合规设计

项目是职业教育与虚拟实训系统，不连接真实 SCADA、DCS、PLC 或油气生产设备；工况、参数、故障和操作情境均为教学模拟或脱敏数据。涉及危险操作时，应以现行法规、企业规程、现场许可和教师判断为准。

项目不采集求职者简历或联系方式；学生账号、作答与画像仅用于授权教学。API Key 仅经后端环境变量注入，不进入前端、日志或版本库。AI 问答、AI 题库和岗位图谱草稿均有显著标识；AI 产物必须经教师审核，且运行时 Prompt 编辑不能关闭权限、安全守卫、结构校验、日期置信度或审核发布规则。

## 七、部署、演示与验证

系统以 `docker-compose up -d --build` 启动，后端启动顺序为 Alembic 迁移、幂等种子写入和 Uvicorn 服务启动。主入口为 `http://localhost:8080`，OpenAPI 文档为 `http://localhost:8000/api/docs`。无模型密钥时可开启 Mock LLM；选择题、评分、画像、推荐与审核等主链路仍可运行。

后端测试覆盖认证、岗位图谱、知识库、结构化分块、RAG、选择题训练、规则评价、能力画像、推荐、教师结果分析、培养方案和安全守卫；前端提供 TypeScript 类型检查与生产构建脚本。建议提交前依次执行后端测试、前端 `npm run type-check`、`npm run build`，并人工复核教师岗位证据页、知识问答引用、学生实训、培养方案分析和安全声明。

## 八、项目价值与后续计划

油训智安将岗位需求、权威知识、教师审核、确定性评价和学生成长数据组织为闭环，既让 AI 在资料整理、候选生成和语言交互中发挥效率，又通过证据链、版本控制、人工审核与规则评分守住教学可信边界。后续将补充更多职业方向的知识与任务证据，完成可授权的教师/学生试用记录，扩展多模态资料解析和跨校分析能力。
