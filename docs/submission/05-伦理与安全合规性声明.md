# 伦理与安全合规性声明

项目名称：油训智安（OilTrainSafe）——面向油气储运工程专业的岗位智能实训与安全能力评测系统

参赛单位：____________________________　　团队名称：____________________________

## 一、声明目的

本团队依据比赛方案关于数据、人工智能生成内容、知识产权和伦理安全的要求，对项目的数据来源、模型使用、教学评价和部署边界作出如下声明。本声明所述控制措施已落实到当前系统；签字和盖章栏须由参赛单位在正式提交前完成。

## 二、数据与隐私承诺

- 系统不使用未经授权或未去标识化的个人数据训练、测试或展示模型；演示学生账号、作答与能力画像均为教学模拟或脱敏数据。
- 公开岗位证据仅处理招聘单位公开发布的岗位名称、职责、任职要求、来源网址和发布日期，不采集或保存求职者简历、电话、身份证件等个人信息。
- 教师上传文件仅用于获得授权的教学知识库；系统通过文件哈希和正文指纹防止重复导入，并支持按章节、条款分块后逐块启用或停用。
- API Key 仅由后端环境变量注入，不写入前端、运行日志、Prompt 管理页面或版本库；正式部署须更换演示密码和 JWT 密钥。

## 三、真实性与可追溯承诺

- 不伪造学术数据、行业统计、岗位发布日期、政策文件、标准编号、章节、页码或引用关系，不使用虚假参考文献。
- 60 条权威知识摘要均保存来源名称、编号、章节和来源 PDF 实际页码；教师上传知识与内置权威摘要分开管理，不自动冒充权威来源。
- 经人工核验的岗位与产业证据保留公开网址、发布机构、发布日期、来源级别和内容指纹。岗位需求趋势仅使用可核验的岗位发布日期，采集时间不替代发布时间。
- 官方网页或官方 PDF 明确日期记为高置信度；高校就业网等可信转载明确日期记为中置信度；无法核验日期的记录不进入时间趋势。
- 系统按原始网址跨采集批次去重，不把同一公告拆分或重复采集来放大岗位需求。趋势结果仅代表系统可追溯样本，不宣称等同于全市场统计。

## 四、AI 生成内容标识与人工审核

- 专业知识问答在页面标题、每条助手回答和生成状态处显著标注“AI 生成内容”，并提示用户依据引用来源核验。
- AI 生成题库在教师端标注“AI 生成内容 · 发布前须教师审核”；教师可逐题修改题干、选项、正确答案、分值、反馈和解析，审核发布前学生不可见。
- 学生端仅对来源于 AI 的已发布题目标注“AI 生成题目 · 已经教师审核”。学生最终成绩只读取数据库中已发布的选项分值，模型不参与作答时评分。
- AI 岗位能力图谱以草稿形式显示模型、去重证据数和置信度，并标注“AI 生成内容”；经教师审核发布后才进入正式岗位图谱。
- 培养方案调整依据岗位动态、产业证据、权威标准和课程映射生成，由教师编辑、核验和发布；系统不以学生成绩自动修改专业培养方案。

## 五、教学与生产安全边界

- 本系统用于职业教育与虚拟实训，不连接真实 SCADA、DCS、PLC、仪表或现场控制设备，不执行生产控制指令。
- 工况、参数、故障和操作情境为教学模拟或脱敏数据，不构成真实现场操作规程、应急指令或安全许可。
- 涉及高风险操作的学习内容必须以现行法律法规、企业制度、现场规程、作业许可和教师指导为准；模型输出不能替代专业人员判断。
- 系统的权限、安全守卫、结构校验、来源校验、评分规则和教师审核发布流程由代码控制，Prompt 修改不能绕过上述约束。

## 六、知识产权与使用规范

- 项目仅保存对公开标准、法规和报告的教学化摘要及必要的溯源元数据，不复制或重新分发受版权保护的完整原文。
- 项目引用第三方公开材料时标明来源；模型生成内容不冒充人工原创或权威结论。
- 团队承诺遵守比赛规则、适用法律法规、开源许可证和第三方服务条款，不实施学术不端、数据造假或其他伦理违规行为。

## 七、风险处置与责任

- 发现错误引用、过期规定、敏感信息或不当模型输出时，教师/管理员可停用知识块、撤回题库批次、归档图谱版本或禁用产业证据，并保留修改记录。
- 若外部模型、Embedding、Reranker 或公开搜索服务不可用，系统明确报告服务状态或安全降级，不伪造调用成功和证据结果。
- 本团队对正式提交材料的真实性与合规性负责，并接受主办方核验。
