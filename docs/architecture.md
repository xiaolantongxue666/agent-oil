# 系统架构

## 双闭环

```text
专业层：公开岗位发布日期 + 岗位图谱 + 产业证据 + 权威标准
      → 课程能力覆盖差距 → 调整草案 → 教师审核 → 培养方案新版本

学生层：发布题库 + 选择题作答 → 数据库规则评分 → 六维能力画像
      → 知识掌握度 → 补学/重练 → 新结果重新计算路径
```

两条链路的数据边界固定：专业培养方案分析不读取学生成绩；学生自适应学习不自动修改专业培养方案。

## 运行分层

```text
Vue 3 / TypeScript / Element Plus / ECharts
                    │ /api
FastAPI 路由、JWT 权限、Pydantic 输入输出
                    │
岗位发现与分析 | RAG | 题库生成 | 规则评分 | 培养方案分析
                    │
PostgreSQL | Qdrant | LLM/Embedding/Reranker Gateway
```

- PostgreSQL 是岗位、图谱、题库、成绩、方案版本和证据元数据的事实来源。
- Qdrant 只保存启用知识块的向量索引；教师停用块不会继续参与检索。
- LLM 只负责语言生成和候选结构，不控制权限、发布、评分或安全边界。
- 公开岗位快照保留原始网址、发布时间、采集时间、日期置信度和内容指纹。

## 核心链路

### 教师上传知识

文件哈希/正文去重 → 解析页码与标题层级 → 章节条款优先分块 → 能力/知识点推荐 → 教师启停与修订 → 启用块进入向量索引和图谱证据关系。

### 岗位动态

教师配置岗位 → 重点企业官方来源优先 → 白名单补充 → 提取岗位正文与发布日期 → 相关性过滤 → URL 去重 → 时间趋势/高频技能 → AI 图谱草稿 → 教师审核发布。

### 选择题实训

教师生成或编辑题库草稿 → 结构校验 → 教师发布批次 → 学生会话锁定批次 → 逐题选择 → 数据库选项分值评分 → 能力画像与个性化路径。

## 部署

Docker Compose 编排前端、后端、PostgreSQL、Qdrant 和 Nginx。运行时 Prompt、证据和业务状态保存在数据库；修改代码或镜像内资源后使用 `docker-compose up -d --build`，只改 `.env` 时重建对应容器以读取新环境变量。
