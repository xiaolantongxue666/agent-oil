# 油训智安：当前状态与后续计划

最后更新：2026-08-13

## 当前可运行链路

- 6 个正式专业岗位及“岗位—任务—能力—知识—技能”图谱。
- 教师创建岗位、公开证据发现、发布日期核验、AI 图谱草稿、人工审核发布。
- 60 条带来源编号/章节/PDF 页码的权威知识摘要；教师上传文件按章节条款分块并逐块启停。
- 专业 RAG 问答，回答带引用并显示 AI 生成标识。
- AI/本地规则题库草稿、教师逐题审核、版本发布、学生选择题实训和数据库规则评分。
- 教师按岗位动态、产业证据和课程覆盖分析培养方案；学生按个人结果进入自适应学习。
- Docker Compose 自主部署，不依赖第三方 Agent 编排平台。

## 证据与数据边界

- 教学工况、学生数据和演示账号是模拟/脱敏数据。
- `backend/app/evidence/verified_public_evidence.json` 保存人工核验的公开岗位时间样本和产业证据。
- 岗位趋势只使用可核验的岗位发布日期；采集时间不参与归月。
- 无可靠日期的联网结果仍可用于技能分析，但不得计入时间趋势。
- `TEST`、`TEST-2` 等开发岗位在启动种子任务时清理，正式岗位不受影响。

## 近期优先事项

1. 完成 2—3 位真实教师/学生的可授权测试记录与改进闭环。
2. 继续积累中国石油、中国石化、国家管网及其直属单位的可核验岗位发布日期样本。
3. 补齐报名表、使用说明、演示视频、测试反馈和签章后的伦理安全声明。
4. 正式评审环境更换演示密码与 JWT 密钥，执行全量回归并导出演示快照。

```bash
cd backend
pytest

```
