# 安全、隐私与 AI 使用边界

## 教学安全

- 本系统是职业教育和虚拟实训系统，不连接真实 SCADA、DCS、PLC 或现场设备。
- 工况、参数、故障和操作情境为教学模拟/脱敏数据，不构成真实生产操作规程。
- 涉及危险操作时，页面结论必须以现行法规、企业规程、现场许可和教师判断为准。

## 数据与隐私

- 公开岗位证据只保存招聘单位公开的岗位职责、任职要求、网址和时间，不采集求职者简历、联系方式或其他个人信息。
- 学生账号、作答和画像仅用于授权教学场景；正式部署应修改演示账号、限制数据库权限并建立备份/删除流程。
- API Key 只通过后端环境变量注入，不进入前端、日志、Prompt 管理页面或版本库。

## AI 生成内容

- 专业问答、AI 题库和 AI 岗位图谱草稿均显示显著 AI 标识。
- AI 题库和岗位图谱必须经教师审核后发布；学生成绩只按数据库中已发布的选项分值计算。
- 引用缺失时不编造来源编号、章节、页码或发布日期。
- Prompt 编辑不能绕过权限、安全守卫、结构校验、日期置信度和教师审核发布规则。

## 输入、引用与流式输出防护

- 输入安全守卫在加载个人业务事实和运行问答流程前执行，会拦截忽略既有指令、索取系统/开发者提示词、要求泄露内部规则等 Prompt Injection 请求。
- 问答中的业务事实与 RAG 知识库结果分开处理；业务结果不会由知识库内容替代。模型声明的引用还要经过代码筛选和二次核验，未核验的来源编号、章节、页码和发布日期不会对外展示。
- SSE 流式输出使用安全句段缓冲，不直接逐 token 放行模型内容；引用标记在完整答案核验后再通过替换事件回填。输出守卫拒绝时，前端收到安全替换内容而不是未经检查的原始片段。
- 选择题实训的最终成绩不受模型输出影响，只使用数据库中已发布选项的分值。

## 证据分级

- 高：企业/政府官方网页或 PDF 明确给出发布日期。
- 中：高校就业网站等可信转载明确给出发布日期，并在记录中注明转载属性。
- 低：只有采集时间、搜索摘要不完整或无法核验页面日期；不进入时间趋势。

正式提交用伦理安全声明见 `docs/submission/05-伦理与安全合规性声明.md` 及生成的 PDF。
