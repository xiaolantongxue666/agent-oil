# “油训智安”比赛演示视频脚本

## 演示定位

**建议时长：7-9 分钟。** 以“岗位—任务—训练—评价—画像—推荐”的教学闭环为主线，依次呈现教师侧建设与审核、学生侧学习与反馈、专业层培养方案迭代。所有操作均在教学模拟环境完成；不连接真实 SCADA、DCS、PLC 或油气生产设备。

## 演示前准备

1. 启动系统：`docker-compose up -d --build`，浏览器访问 `http://localhost:8080`。
2. 准备教师账号 `teacher / teacher123` 与学生账号 `student / student123`。仅用于演示，正式评审环境应替换密码和 JWT 密钥。
3. 优先使用已发布岗位与题库；如现场网络不稳定，使用已内置的 6 个岗位、60 条权威知识摘要和已发布选择题完成主流程。
4. 录屏前关闭无关通知；浏览器缩放设为 100%，分辨率建议 1920×1080。

## 现场问答备用说明

- **“AI 是否直接评分？”** 不直接评分。当前选择题实训的最终分数只读取数据库选项分值，`semantic_score` 与 `llm_score` 为 0；AI 仅生成题库草稿或语言类候选内容。
- **“如何保证引用可信？”** 权威知识摘要保留来源编号、章节和 PDF 页码；教师上传资料需要逐块审核启用；岗位趋势只使用可核验的发布日期，采集时间不替代发布日期。
- **“如何保证教学安全？”** 系统定位为职业教育与虚拟实训，不连接真实生产设备，不提供可直接用于现场的危险控制指令；页面与材料均声明教学模拟边界。
- **“如何离线演示？”** 无模型密钥时，LLM Gateway 可降级为 Mock；题库也可选择本地规则模板，岗位图谱、题库审核、选择题规则评分、画像和推荐等核心业务链路仍可演示。
