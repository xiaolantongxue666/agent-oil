# 知识库补充资料（2026-08-30）

本目录为"油训智安"知识库的补充教学资料，全部为**教学模拟/脱敏内容**，用于教师端"知识库管理"上传（`POST /api/knowledge/upload`，支持 PDF / DOCX / TXT / Markdown），经教师审核启用后进入向量检索与图谱证据关系。

> 注意：README 中提到的 `scripts/import_knowledge.py` 已不存在于仓库，当前唯一导入入口是教师端上传接口/页面。

## 一、为什么补这批资料（缺口结论）

|------|--------|----------|
| 长输油气管道站场运行 | 中（管道保护法 + 巡检/阀门样例） | K-SUP-PIPE-01 |
| 油气集输运行 | 几乎空白 | K-SUP-GATHER-01 |
| 原油输送运行 | 几乎空白 | K-SUP-OIL-01 |
| 天然气输送运行 | 少量 | K-SUP-PIPE-01、K-SUP-GAS-01 |

## 三、上传与审核步骤

1. 教师账号登录 → 知识库管理 → 上传文件（支持批量逐个上传）。
2. 系统自动：哈希与正文查重 → 章节分块（本批文档按"第X章/X.Y"结构编写，块均低于 1800 字符上限）→ 关键词匹配推荐六维能力与图谱知识点（正文中已内置"工艺流程、离心泵、压缩机组、泄漏风险、动火、巡检记录"等知识点关键词）。
3. 教师复核每块全文与推荐结果，启用合格块、停用声明/目录类无关块。
4. 启用块进入 Qdrant 检索；"启用且已映射知识点"的块进入图谱证据关系。

## 四、内容边界说明

- 全部资料为教学模拟或教学化改写内容，**不含**任何标准/法规原文，也未虚构标准编号；具体数值均标注"教学模拟值"。
- 与系统安全边界一致：不输出可作用于真实现场的操作指令，不冒充权威来源（教师上传文件与 60 条权威摘要仍是两类数据）。
- 如需扩充权威来源，建议由课程组人工核验后按 `authoritative_knowledge.json` 的字段规范（source/page/chapter 等）增补，页码须对应真实 PDF。
